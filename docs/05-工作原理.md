# 05 · 工作原理（逆向记录）

> 记录实测过程与结论，方便后续维护。所有测试都在 2026-11 进行。

## 1. 服务端接口

| 接口 | 方法 | 作用 |
|---|---|---|
| `/api/v1/auth?uid=<UID>&v=3.2.9` | GET | 查余额；**首次出现的 UID 会自动注册** |
| `/api/v1/cx?v=3.2.9` | POST | 答题，body: `question=&u=<UID>&model=GPT-3.5` |
| `/api/security/captcha/refresh` | POST | 刷新图片验证码（限流时触发） |

响应示例：

```json
// 注册/查余额
{"code":"200","data":{"score":"20","models":"<option ...>","notice":"..."}}

// 答题成功
{"code":"200","data":{"answer":"81"}}

// 失败
{"code":"400","msg":"积分不足,请充值,如已充值请刷新页面"}
{"code":"429","msg":"请求过于频繁,请稍后重试"}
{"code":"400","msg":"由于该模型官方定价较高,请充值月卡后使用"}
```

## 2. 三个关键缺陷

### 2.1 `uid=0` 不计费

服务端只在 `uid > 0` 时进入扣费分支：

```
POST /api/v1/cx  u=0&model=GPT-3.5
→ 200 {"answer":"..."}   // 不扣任何积分
```

但每个出口 IP 的免费额度约 20 次，用完后返回 `400 积分不足`，
且**不是每日重置**（连续观察 8 小时、跨夜均未恢复）。

### 2.2 新号赠送 20 积分

首次请求 `auth?uid=<新UID>` 会自动建号并赠 20 分（1 题 1 分）。
但**注册额度按出口 IP 计**：同一 IP 连续注册会得到

```
第 1 次：200 score=20
之后：  429 请求过于频繁
或：    200 score=0（建号成功但不送分）
```

### 2.3 UID 不绑定 IP

用 A 网络注册出来的 UID，在 B 网络直接 `POST /cx` 依然 200。
→ 因此**只需在注册环节换 IP**，答题可以全部本地直连，速度快且稳定。

## 3. 脚本架构

```
src/crack_module.js
├─ crackAsk()          主流程：免费通道 → 账号池 → 现铸号 → 回退
├─ crackChannel()      单账号请求：双镜像 + 429/5xx 重试
├─ crackPool*()        账号池读写（localStorage，按积分排序）
├─ crackMintRound()    一轮铸号：直连 + 多个 CORS 中转并发
├─ crackKeeperTick()   后台补池：池内积分低于阈值就补
└─ CRACK_RELAYS        公共 CORS 中转列表（换出口 IP 用）
```

### 为什么需要 CORS 中转

浏览器里 JS 无法直接换出口 IP。用一个"帮你转发请求"的公共 CORS 服务，
请求就从**那台服务器**发出，出口 IP 变了 → 相当于一个干净 IP。

接口本身对 `chaoxing.com` 系列 Origin 返回
`Access-Control-Allow-Origin: <你的域名>`，所以页面内 `fetch` 直连答题没有跨域问题；
中转只用于注册环节。

### 中转调度

- 每个中转记录**成功次数**（`GPTJsCrack.relayScore`），优先用命中率高的
- 429 → 该中转冷却 3 分钟；超时 → 1 分钟；返回 `score=0`（IP 已被领过）→ 10 分钟
- 一轮失败 → 下一轮间隔 ×1.6 指数退避，最长 5 分钟；成功一次即复位

## 4. 与其它实现的对比

| 方案 | 结论 |
|---|---|
| 随机 UID 每次请求都换 | ❌ 注册额度按 IP，换 UID 没用，全部 429 |
| 本地常驻代理池 + 本地中转服务 | ✅ 有效，但需要跑 Python 服务、维护代理列表 |
| 公共 CORS 中转（本项目） | ✅ 无需本地进程，成功率取决于中转可用性 |
| 预置账号池 | ✅ 最稳，但有"共享账号被抢额度"的问题，故不随仓库发布 |

## 5. 已知限制

- 公共 CORS 中转会被自身限流，稳态大约几分钟铸 1~2 个号
- 服务端随时可能修掉 `uid=0` 或改为 `uid >= 0`，届时需重新逆向
- 非 GPT-3.5 档位需要月卡，无免费路径
