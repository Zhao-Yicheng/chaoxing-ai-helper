# 01 · 快速开始（零基础版）

## 这东西能干嘛

打开学习通的作业 / 考试页面后，页面右上会出现一个悬浮面板。
点「开始答题」，脚本会：

1. 逐题读取题干和选项
2. 调 AI 生成答案
3. 自动勾选 / 填空
4. 自动提交（可在设置里关掉）

全程**不花你一分钱**，因为脚本走的是服务端的免费通道 + 自己批量注册的免费额度账号。

---

## 有两种装法，怎么选

### 选「油猴脚本」如果：

- 你的浏览器已经装了 **Tampermonkey** 或 **ScriptCat**
- 你希望以后更新只要点一下（脚本带自动更新地址）

→ 看 [02-脚本版安装教程](02-脚本版安装教程.md)

### 选「浏览器扩展」如果：

- 你没装过任何脚本管理器，不想多装东西
- 你怕复制粘贴出问题（扩展是整包加载，不涉及粘贴）

→ 看 [03-扩展版安装教程](03-扩展版安装教程.md)

> **千万不要两个都装。** 同一个页面会注入两次，出现两套面板互相抢答题，
> 情况会表现为"卡住不动"或"题目被跳过"。

---

## 装完之后怎么确认成功

1. 打开任意学习通页面（例如课程 → 作业）
2. 按 `F12` 打开开发者工具 → 切到 **Console（控制台）** 标签
3. 看到类似下面这几行就是成功了：

```
[CRACK] 账号池就绪: 0 个号（本次灌入 0 个种子），可用题目约 0 道
[CRACK] 后台补池已启动：目标 200 分，每 45s 检查一次
[CRACK] 账号池偏低（0 个号 / 0 分），后台补充中...
[CRACK] 铸号成功 [cors.eu.org/] 38372065 +20 分
```

- `账号池 ... 0 个号` 是正常的：本版本**不带预设账号**，全靠后台自己造
- 等 10~60 秒，会陆续出现 `铸号成功 ... +20 分`
- 池里攒到 20 分（1 个号）就能答 20 道题

页面上同时会出现悬浮面板，顶部写着
`免积分破解模式：答题走免费通道，不消耗积分` 和 `账号池：N 个号 / 约 M 道题（后台自动补充）`。

---

## 第一次用建议这么操作

1. 先安装，然后**刷新页面**，等控制台出现第一条 `铸号成功`
2. 进一个作业页面，把面板的「答题间隔」调到 **5 秒**（默认 2.5 秒，第一次求稳）
3. 点「开始答题」，观察前 2~3 题是否正常填写
4. 正常就继续；如果出现"账户余额不足"，说明池子空了，等 1~2 分钟再点
