# 03 · 扩展版安装教程（Chrome / Edge）

适用：Chrome、Edge 等 Chromium 内核浏览器，版本 **≥ 111**（2023 年以后的基本都满足）。

产物文件：`dist/chaoxing-ai-helper-extension.zip`

---

## 为什么不直接双击装？

本扩展没有上架 Chrome 应用商店（这类工具上不了架），所以要用**开发者模式加载本地扩展**。
听着吓人，其实就 4 步，一次装好长期有效。

---

## 第 1 步：下载并解压

1. 到 [Releases](https://github.com/Zhao-Yicheng/chaoxing-ai-helper/releases) 页面，下载 `chaoxing-ai-helper-extension.zip`
   （或从仓库里下载 [`dist/chaoxing-ai-helper-extension.zip`](../dist/chaoxing-ai-helper-extension.zip)）
2. **解压**到一个你不会随手删掉的目录，例如 `D:\学习通助手\`
3. 解压后目录里应该能看到：

```
chaoxing-ai-helper-extension\
├─ manifest.json
├─ src\
│  └─ bundle.js
└─ icons\
```

> ⚠️ 一定要记住这个路径。**加载的是这个文件夹本身，不是 zip**。

---

## 第 2 步：打开扩展管理页

在地址栏输入：

- Chrome：`chrome://extensions`
- Edge：`edge://extensions`
- 其他 Chromium 浏览器：一般在 `chrome://extensions` 或设置里搜"扩展"

---

## 第 3 步：开启开发者模式 + 加载

1. 右上角找到 **开发者模式 / Developer mode** 开关 → **打开**
2. 页面左上（Edge 是左下）出现三个按钮：**加载已解压的扩展程序 / Load unpacked**
3. 点它 → 在弹出的文件选择框里选中**第 1 步解压出来的文件夹**（就是含 `manifest.json` 的那一层）
4. 列表里出现一张卡片：

```
学习通AI答题助手（免积分版）
3.2.9
```

= 安装成功。

> 也可以**直接把解压后的文件夹拖进**扩展管理页面，效果一样。

---

## 第 4 步：确认生效

1. 打开任意学习通页面（`mooc1.chaoxing.com` 之类）
2. 按 `F12` → **Console**
3. 看到 `[CRACK] 后台补池已启动` = 成功

如果控制台没有任何 `[CRACK]` 日志：

- 先**刷新页面**（扩展只在页面加载时注入）
- 检查扩展卡片上有没有红色 **错误** 按钮，点开看报错
- 确认浏览器版本 ≥ 111（设置 → 关于 Chrome 可查看）

---

## 常见安装报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `Manifest file is missing or unreadable` | 选错了文件夹 | 必须选含 `manifest.json` 的那一层 |
| `manifest_version` 相关错误 | 浏览器太老 | 升级到 Chrome/Edge 111+ |
| 卡片显示但页面上没反应 | 页面没刷新 / 域名不在列表 | 刷新页面；确认是 `chaoxing.com` / `xuexitong.com` 等域名 |
| 和油猴脚本同时装了 | 重复注入 | 停用其中一个 |

---

## 更新扩展

1. 下载新版 zip → 解压**覆盖**原来的文件夹（先删旧内容再解压，避免新旧文件混在一起）
2. `chrome://extensions` 里点该卡片上的 **刷新/更新** 图标
3. 回学习通页面刷新

---

## 卸载

`chrome://extensions` → 卡片右下 **移除** → 再把文件夹删掉。

---

## 和油猴版的区别

| | 油猴脚本 | 扩展版 |
|---|---|---|
| 需要先装的东西 | Tampermonkey / ScriptCat | 无 |
| 依赖库 | 在线 `@require` 加载或打包 | 全部内嵌，断网也能起 |
| 注入方式 | 脚本管理器沙箱 | 页面主世界（MAIN world） |
| 更新 | 自动 | 手动覆盖 |

功能、账号池逻辑、答题效果**完全一致**。
