# 02 · 脚本版安装教程（Tampermonkey / ScriptCat）

适用：Chrome、Edge、Firefox、以及基于 Chromium 的国产浏览器（360、QQ、夸克等）。

产物文件：`dist/chaoxing-ai-helper.user.js`

---

## 第 1 步：装一个脚本管理器

脚本本身不能直接跑，需要"脚本管理器"承载。二选一：

### 方案 A：Tampermonkey（推荐，老牌）

1. 打开扩展商店：
   - Chrome：<https://chrome.google.com/webstore/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo>
   - Edge：<https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd>
   - Firefox：<https://addons.mozilla.org/firefox/addon/tampermonkey/>
2. 点「添加到浏览器」→ 确认安装
3. 浏览器右上角出现一个**黑色方块带两个白点**的图标 = 装好了

### 方案 B：ScriptCat（脚本猫，国内访问快）

1. 打开 <https://scriptcat.org/> → 首页点「安装扩展」
2. 或直接在扩展商店搜 **ScriptCat**
3. 装好后右上角出现橙色小猫图标

> 两者都行，本文以 Tampermonkey 为例，ScriptCat 的操作几乎一样。

---

## 第 2 步：拿到脚本文件

从本仓库下载：

- 方式一：打开 [`dist/chaoxing-ai-helper.user.js`](../dist/chaoxing-ai-helper.user.js) → 右上角 **Download raw file**（下载箭头图标）
- 方式二：到 [Releases](../../releases) 页面下载 `chaoxing-ai-helper.user.js`

下载后得到一个 `.user.js` 结尾的文件（注意：有的浏览器会把它存成 `.txt`，那就手动改名回 `.user.js`）。

---

## 第 3 步：导入脚本

> ⚠️ **不要用"复制全文 → 新建脚本 → 粘贴"**。
> 这个脚本有 6000 多行、约 280KB，浏览器编辑器粘贴时**有概率被截断**，
> 表现就是控制台报 `Uncaught SyntaxError: Unexpected token ')'`。用下面两种方式导入文件最稳。

### 方式 1：拖拽（最快）

把下载好的 `.user.js` 文件**直接拖进浏览器窗口**，Tampermonkey 会弹出安装页 → 点 **安装**。

### 方式 2：从文件导入（最稳）

1. 点浏览器右上角 Tampermonkey 图标 → **管理面板 / Dashboard**
2. 切到 **实用工具 / Utilities** 标签
3. 找到 **从文件导入 / Import from file** 区块
4. 点 **选择文件** → 选中 `chaoxing-ai-helper.user.js`
5. 弹出安装页 → 点 **安装**

### 方式 3：网址安装（如果你把脚本放到了自己的服务器）

Tampermonkey 会自动识别 `.user.js` 结尾的地址并弹出安装页。
本仓库的 raw 地址也可以直接用：
`https://raw.githubusercontent.com/Zhao-Yicheng/chaoxing-ai-helper/main/dist/chaoxing-ai-helper.user.js`

---

## 第 4 步：确认装好了

1. Tampermonkey 图标上会出现一个红色数字 **1**（表示当前页面有 1 个脚本在跑）
2. 打开任意学习通页面（例如 <https://mooc1.chaoxing.com/>）
3. 按 `F12` → **Console**
4. 看到 `[CRACK] 后台补池已启动` 之类日志 = 成功

### 看到的日志含义

| 日志 | 含义 |
|---|---|
| `账号池就绪: 0 个号` | 正常，本版本不带预设号 |
| `后台补池已启动` | Keeper 已开始工作 |
| `铸号成功 [cors.eu.org/] xxxx +20 分` | 成功造了一个 20 分的新号 |
| `铸号失败 [xxx] http=429` | 该中转被限流，脚本会自动冷却并换站 |
| `用号 xxxx 答题成功` | 正在用池里的号答题 |
| `免费额度已耗尽，30 分钟内直接走账号池` | `u=0` 免费通道用完了，转用账号池 |

---

## 第 5 步：开始答题

1. 进入课程 → 作业 / 考试页面
2. 右侧出现悬浮面板（如果不显示，按 **F9** 或点面板边缘）
3. 确认「模型」是 `GPT-4.1 (普通｜低价)`（这是唯一免费档位，别改）
4. 点 **开始答题**
5. 第一次建议把「间隔」改成 5 秒，观察 2~3 题正常后再继续

---

## 更新脚本

- Tampermonkey 会自动检查更新（脚本里已配置 `@updateURL`），管理面板里点「检查用户脚本更新」即可
- 手动更新：重新执行第 3 步导入新文件，选择「覆盖」

---

## 卸载

Tampermonkey 管理面板 → 脚本右侧 **删除**。
